# Online-Blogging-System
Blogging System web application built using PHP &amp; MySQL, for the users to create and categorize blogs with secure authentication.

## 🚀 Features
* User registration and secure login system
* Create, read, update, and delete (CRUD) blog posts
* categorize blogs
* Responsive user interface

## 🛠️ Prerequisites
To run this project locally, you will need:
* A local server environment like **XAMPP** or **WAMP**
* PHP (7.4 or higher recommended)
* MySQL Database

### 1. Clone or Download the Project
Move this project folder into your local server directory:
* For XAMPP: `C:/xampp/htdocs/Online-Blogging-System`
* For WAMP: `C:/wamp64/www/Online-Blogging-System`

### 2. Import the Database
1. Open your browser and go to `http://localhost/phpmyadmin/`.
2. Click on **New** in the left sidebar to create a new database.
3. Name the database (e.g., `blog`) and click **Create**.
4. Click on your newly created database, then click the **Import** tab at the top.
5. Click **Choose File** and select the `blog.sql` file from this project folder.
6. Scroll to the bottom and click **Import** (or **Go**).

### 3. Run the Project
Start your Apache and MySQL modules in your XAMPP/WAMP control panel. Then, open your browser and visit:
`http://localhost/Online-Blogging-System/`
